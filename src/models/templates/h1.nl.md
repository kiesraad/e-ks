### In te leveren bij de kandidatenlijst

Ik ben verplicht de volgende bijlage(n) in te leveren bij de kandidatenlijst:

{% if list_designation != ListDesignation::Blank %}
- [x] Een verklaring van de gemachtigde(n) van de politieke groepering(en) waarmee
  aan mij toestemming wordt gegeven om de aanduiding boven de kandidatenlijst te
  plaatsen, want ik heb een aanduiding boven de lijst geplaatst (model H 3-1 of H 3-2).
{%- endif %}
{%- if !previously_seated %}
- [x] Verklaringen van kiezers dat zij de lijst ondersteunen, want de lijst komt niet
  in aanmerking voor de ontheffing van deze verplichting
  ({% if common.election_type == ElectionType::Kcni %}model Pa 11{% else %}model H 4{% endif %}).
{%- endif %}
- [x] Een verklaring van iedere op de lijst voorkomende kandidaat dat hij instemt met
  zijn kandidaatstelling op de lijst (model H 9).
- [x] Een kopie van een geldig identiteitsbewijs van iedere kandidaat die géén zitting
  heeft in het orgaan waarvoor de verkiezing wordt gehouden.
{%- if !previously_seated %}
- [x] Een betalingsbewijs van de waarborgsom, want de lijst komt niet in aanmerking
  voor de ontheffing van deze verplichting (model H 12).
{%- endif %}
{%- if self.residence_declaration_required() %}
- [x] Een verklaring van voorgenomen vestiging van iedere op de lijst voorkomende
  kandidaat die niet woonachtig is in het gebied waarop de verkiezing betrekking
  heeft (alleen bij een verkiezing van provinciale staten, het algemeen bestuur van
  een waterschap, een gemeenteraad, de eilandsraden van de openbare lichamen Bonaire,
  Saba of Sint Eustatius en de kiescolleges van de openbare lichamen).
{%- endif %}
{%- if common.election_type == ElectionType::Kcni %}
- [x] Een verklaring van voorgenomen vestiging buiten Nederland van iedere op de
  lijst voorkomende kandidaat die woonachtig is in Nederland (alleen bij een
  verkiezing van het kiescollege voor niet-ingezetenen).
{%- endif %}
{%- if common.election_type == ElectionType::Ep %}
- [x] Een verklaring van iedere op de lijst voorkomende kandidaat dat hij niet in een
  andere lidstaat kandidaat zal zijn voor het Europees Parlement (model Y 13).
- [x] Een verklaring van kandidaten die onderdaan zijn van een andere lidstaat, dat
  zij in die lidstaat niet zijn uitgesloten van het recht om gekozen te worden voor
  de verkiezingen van het Europees Parlement (model Y 35).
{%- endif %}
