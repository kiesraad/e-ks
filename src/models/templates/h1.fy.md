### Yn te leverjen by de kandidatelist

{% if list_designation != ListDesignation::Blank %}

  want ik haw in oantsjutting boppe de list pleatst (model H 3-1 of H 3-2).
{%- endif %}
{%- if !previously_seated %}

{%- endif %}
- [x] In ferklearring fan alle op de list foarkommende kandidaten dat se ynstimme

{%- if !previously_seated %}
- [x] In betellingsbewiis fan de boarchsom, want de list komt net yn oanmerking foar

{%- endif %}
{%- if self.residence_declaration_required() %}
- [x] In ferklearring fan foarnommen fêstiging foar alle op de list foarkommende

  (allinnich by in ferkiezing fan provinsjale steaten, it algemien bestjoer fan in
  wetterskip, in gemeenteried, de eilânrieden fan it iepenbiere lichem Bonêre, Saba
